# 🎨 Drawing Task Manager

เว็บแอปพลิเคชันสำหรับจัดการงานวาดรูปและงานการ์ตูน
พัฒนาด้วย Node.js, Express.js, HTML, CSS และ JavaScript

## Features

- แสดงรายการงาน
- เพิ่มงาน
- แก้ไขงาน
- ลบงาน
- กรองงานตามสถานะ
- REST API
- ข้อมูลถูกเก็บใน JSON file
- Frontend ใช้ Fetch API
- ไม่ต้อง Reload หน้าเว็บเมื่อเพิ่ม แก้ไข หรือลบข้อมูล

---

## Technologies

- Node.js

- HTML5

- JavaScript
- REST API
- Fetch API
